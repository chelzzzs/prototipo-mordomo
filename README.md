# prototipo-mordomo

# Mordomo Financeiro · Protótipo

> **Trabalho acadêmico.** Este repositório é um trabalho de faculdade, feito para uma disciplina do curso de Análise e Desenvolvimento de Sistemas da PUC-PR. Não é um produto real nem um serviço em funcionamento: o app não se conecta a bancos, não coleta dados e todas as informações exibidas são fictícias.

Protótipo navegável de alta fidelidade do **Mordomo Financeiro**, um aplicativo de finanças pessoais com assistente de IA em formato de mordomo particular.

**Acesse:** https://chelzzzs.github.io/prototipo-mordomo/

## Como navegar

- No computador, o protótipo abre em uma moldura de celular, com o índice de telas ao lado.
- No celular, ocupa a tela inteira.
- Botões, abas e links levam às telas correspondentes. Cada tela também pode ser aberta pelo endereço, por exemplo `#inicio` ou `#painel`.

## Tecnologia

HTML, CSS e JavaScript em um único arquivo (`index.html`), sem dependências além das fontes do Google Fonts.

Os bancos aparecem apenas como exemplos de opção de conexão. As personas (Sofia Martins e Renata Costa), os valores e as transações foram criados para a atividade.
